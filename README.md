**Notebook:** `Skill/DecisionTree.ipynb`

Topics covered include:

- Understanding tree-based learning.
- Splitting data using feature criteria.
- Training and making predictions.
- Evaluating model performance.
- Understanding how algorithms learn from data.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/baharth06/ML.git
cd ML
```

### 2. Install the required packages

```bash
python -m pip install jupyter pandas numpy matplotlib seaborn scikit-learn
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 4. Start exploring

Open a notebook, execute the cells, study the results, and experiment with the code.
